# Resume–JD AI Analyzer

An AI-powered system that analyzes a candidate's resume against a job description using LLM + RAG.

## Features (Planned)
- ATS compatibility score
- Skill gap analysis
- Role match percentage
- AI-generated resume improvements
- Recommended projects to close skill gaps

## Tech Stack
- LLMs (OpenAI / Gemini)
- Vector Database (FAISS)
- Backend: Python
- Frontend: React
